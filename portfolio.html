Features

What It Does

Packed with everything a student needs to track their academic performance.

📊

Dual Calculation Modes

GPA (Single) mode for per-semester course-level calculation, and CGPA (Multi) mode for cumulative multi-semester tracking.

📝

Marks Sheet

Full data-entry table with Mid, Final, Sessional columns. Total and Grade auto-calculate as you type.

🔄

Bidirectional Sync

Change marks → grade updates. Change grade → marks update. Always in sync, always accurate.

🎨

Glassmorphism UI

Frosted glass cards, mesh gradient background, neomorphic buttons — modern visual design.

⚡

Real-time Stats

Bento grid dashboard with color-coded CGPA (green ≥ 3.5, amber ≥ 2.5, red < 2.5) that updates instantly.

🔬

Lab/Practical Toggle

Special mode for practical courses — doubles marks for grade calculation, simulating a 50-mark scale.

Workflow

How It Works

Simple, intuitive flow for both GPA and CGPA calculation modes.

GPA Mode

1
Select "GPA (Single)" mode from the toggle
2
Add courses with name, credit hours (1-6), and total marks (0-100)
3
Marks auto-convert to letter grades using the 10-grade scale
4
Semester GPA = Σ(grade_points × credits) / Σ(credits)
5
Overall CGPA computed across all semesters in real-time

CGPA Mode

1
Select "CGPA (Multi)" mode from the toggle
2
Add semesters with name, credit hours, and GPA (0.0-4.0)
3
CGPA = simple average of all semester GPAs
